# GeigerCounter

[![Watch the video](https://github.com/noelmann/GeigerCounter/blob/master/Pictures/GeigerCounter.png)](https://github.com/noelmann/GeigerCounter/blob/master/Videos/GeigerCounterDemo.mp4)
# What is it?
It is a geiger counter that uses a soviet SBM-20 tube made in the 1980s.
An arduino nano is used for calculating the estimated dose based on the counts per minute and a rough calibration value. The result is displayed on a 16x2 LCD display.

# Additional information
It is not useful for measuring in environments with high levels of radiation as it can cause the tube to saturate resulting in a false measurement of zero counts per minute.
